# Política de segurança

## Dados locais

Este projeto funciona sem serviços externos. Movimentações, configurações e backups são dados locais e não devem ser enviados ao repositório. Arquivos `.db`, `.sqlite`, `.env`, backups, logs, certificados e chaves privadas são bloqueados pelo `.gitignore`.

Antes de abrir uma issue pública, remova nomes de técnicos, destinos, observações, caminhos pessoais e qualquer dado operacional. Não anexe bancos ou backups.

## Relatando uma vulnerabilidade

Não publique credenciais ou dados pessoais em issues. Envie o relato por um canal privado disponibilizado pelo mantenedor do repositório. Inclua apenas os passos mínimos para reproduzir o problema e mantenha valores sensíveis mascarados.

Se uma credencial tiver sido commitada, considere-a comprometida: revogue-a, gere outra e remova o valor de todo o histórico antes de publicar novamente.
